# Wordlist-Generator

A simple and flexible Python tool to generate custom wordlists for use in security testing, password recovery, or other automation tasks.

## Features

- Generate wordlists of customizable length
- Support for various character sets (letters, digits, symbols)
- Easy to configure and extend
- Fast and lightweight

## Requirements

- Python 3.x

## Installation

Clone the repository:
```bash
git clone https://github.com/rahulhalder123-456/Wordlist-Generator.git
cd Wordlist-Generator
```
(Optional) Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```
## Usage
- Run the generator script:

```bash
python wordlist_generator.py
```
- You can modify script parameters or edit the code to adjust wordlist length, character sets, and output file name.
## Example
```bash
python wordlist_generator.py --length 8 --charset alpha
```
